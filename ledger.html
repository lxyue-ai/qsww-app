基础设置

关于「一键直达本地文件夹 / 文件」：本功能在直接用浏览器打开本文件（file:// 方式）时生效，点击链接即可在资源管理器打开对应文件夹或文件。若通过云端部署地址访问，浏览器出于安全限制无法打开你电脑上的本地路径，此时链接不可用，请改用导出的本地版或复制路径手动打开。

数据备份与恢复

工作台数据全部存于本机浏览器（localStorage），无自动云同步。换电脑 / 清缓存前请导出备份，到新环境用「导入恢复」。
☁ GitHub 云同步 未配置
